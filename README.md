# Basics Well Made

Website for **The Basics Well Made Series**: simple, well-made apps for the Mac, by
[@erfanj](https://github.com/erfanj). Served by GitHub Pages at <https://erfanj.github.io/>.

| Path | App |
|---|---|
| [`/zipper/`](https://erfanj.github.io/zipper/) | Zipper, the archive manager for macOS. Downloads: [erfanj/Zipper releases](https://github.com/erfanj/Zipper/releases) |

The `zipper/` folder is copied from `site/` in [erfanj/Zipper](https://github.com/erfanj/Zipper); edit it there and copy
it here rather than editing it in place. The root page currently forwards to Zipper.
