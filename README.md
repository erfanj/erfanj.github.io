# Basics Well Made

Website for **The Basics Well Made Series**: simple, well-made apps for the Mac, by
[@erfanj](https://github.com/erfanj). Served by GitHub Pages at <https://erfanj.github.io/>.

| Path | App |
|---|---|
| [`/zipper/`](https://erfanj.github.io/zipper/) | Zipper, the archive manager for macOS. Downloads: [erfanj/zipper-releases](https://github.com/erfanj/zipper-releases/releases) |

The `zipper/` folder is published from the app's (private) source repository; edit it there and copy
it here rather than editing it in place. The root page currently forwards to Zipper.
